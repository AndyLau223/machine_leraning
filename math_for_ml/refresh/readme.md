# Math refresh

## Vector notation
- Bold: **v** = (x, y, z)  
- Arrow: \vec{v} = (x, y, z)  
- Column vector (LaTeX): $\displaystyle \begin{bmatrix} x \\ y \\ z \end{bmatrix}$

## Vector magnitude (length)
- 2D: $|\mathbf{v}| = \sqrt{x^2 + y^2}$  
- 3D: $|\mathbf{v}| = \sqrt{x^2 + y^2 + z^2}$  
Example: $\mathbf{v}=(3,4)\Rightarrow |\mathbf{v}|=5$

## Unit vector (normalization)
- Unit vector: $\hat{\mathbf{v}} = \dfrac{\mathbf{v}}{|\mathbf{v}|}$ (has magnitude 1)  
- Standard basis: $\hat{\mathbf{i}}=(1,0,0),\ \hat{\mathbf{j}}=(0,1,0),\ \hat{\mathbf{k}}=(0,0,1)$
